# Introduction

**`gesturx`** is a **gesture** recognizer library written with **`rxjs`** for the **modern** we&#x62;**.** It is fully typed and provide extensive configurations.

## Why `rxjs`?

Using rxjs was a design choice to have a library easy to maintain and develop while being reliable and powerful. It does however increase your package size if you are not already using it. Check below for size comparisons.
