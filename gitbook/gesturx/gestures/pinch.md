# Pinch



A pinch gesture is detected when the user has two inputs or more on the screen moving either closer or away from each other.

Typically used for zooming in/out features.

#### API

[Visit the API here](https://github.com/mbret/gesturx/blob/main/src/core/pinch/PinchRecognizerInterface.ts)

#### Example

```typescript
new PinchRecognizer({
  posThreshold: 0
})
```
